# 发布准备

1. 确认 SDK 链接及二进制再分发许可，记录固件、SDK、工具链标识。
2. 运行 `make test`，构建主程序及 camera/notify/media 全部辅助组件。
3. 在未安装过本应用的目标眼镜验证首次配置、安装、扫码和录音，并验证升级保留数据。
4. 为安装包补齐完整组件备份、回退和卸载能力；现有 deploy 脚本不是完整回退工具。
5. 安装包包含 dist、device、安装/注册脚本、文档、LICENSE、第三方许可文本和校验值，不包含用户配置、凭证、密钥、日志或录音。
6. 标签和 Release 说明关联源码提交，注明兼容服务端 v1 协议、固件标识及已知问题。

当前只完成源码仓库准备；未创建 GitHub Release，也未宣称已经交付正式安装包。SDK 再分发许可与固件版本标识待核实。

# 用户指南

1. 安装眼镜应用后，打开默认线上实例 [https://memo-meeting.easymr.cn](https://memo-meeting.easymr.cn)，注册并登录账号，在「我的眼镜」生成绑定二维码；自部署时使用自己的服务地址。
2. 佩戴眼镜看向二维码，按住原有语音按钮，说“绑定会议账号”，松开并保持对准屏幕。
3. 网页出现待确认设备，核对 clientId 和 MAC，再确认绑定。
4. 按住按钮说“打开会议记录”，松开；等待录音成功反馈后开始会议。
5. 同账号网页可查看实时转录。
6. 按住按钮说“关闭会议记录”，松开；等待尾句与录音保存成功。

未绑定时说“打开会议记录”也会引导扫码，确认后继续开启。只看向二维码不会触发扫码；二维码有效期为 5 分钟。换账号时先在原账号解绑，再重新扫码。

设备重启后凭证自动加载和校验，但不会自动恢复录音。网络失败明确中断，本地 WAV 可由设备维护者取回；不会自动补传。绑定密文与本机密钥的文件权限保护不等于硬件安全隔离。

录音上传到配套服务并按配置提交给外部 AI；设备还会保存本地 WAV。录音前告知参会者，核对转录和纪要中的关键事实。

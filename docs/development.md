# 开发与测试

`make test` 运行 Go 单元测试、语音函数合并测试及 shell 语法检查，不要求连接眼镜，不调用付费 AI。

C 辅助组件由 `make camera notify media` 构建，使用外部 SDK。编译器和 SDK 路径通过 Makefile 参数传入，不写入个人绝对路径。

部署和 USB 调试脚本通过 `ADB_SERIAL` 显式选择设备；`live-transcription.py` 使用 `--serial`。`bind.py` 是旧口令绑定兼容工具，普通用户使用扫码流程。

本地历史联调脚本 `test-device.py` 依赖开发者网络、相邻目录和运行数据，已从公开仓库排除；不属于可复现自动测试入口。

真机验收需覆盖首次安装、扫码与网页确认、重启后绑定恢复、真实语音启停、末句完整性、按键和播报音频过滤、网络中断及原有聊天/视频功能。协议桩不能替代佩戴验收。调试 `--start` 会创建真实录音并可能产生云端费用，应仅对自己的测试账号运行。

# 用户指南

1. 安装眼镜应用后，打开默认线上实例 [https://memo-meeting.easymr.cn](https://memo-meeting.easymr.cn)，注册并登录账号，打开「我的眼镜」；自部署时使用自己的服务地址。
2. 按住眼镜原有语音按钮，说“打开会议记录”或“绑定会议账号”，松开。
3. 未绑定的眼镜会逐位播报四位数字验证码，例如“零、三、八、二”。在网页输入 `0382` 并点击“绑定眼镜”。请保留开头的零。
4. 绑定后自动开启会议，听到“绑定成功，已开始会议记录”再开始会议。已绑定眼镜直接开启，播报“已开始会议记录”。启动失败会提示失败，不能把绑定成功当作录音已经开始。
5. 同账号网页可查看实时转录。
6. 按住按钮说“关闭会议记录”，松开；等待尾句与录音保存成功。

等待绑定期间，每30秒自动重播当前验证码；绑定成功或本次等待超时后停止循环提示。验证码有效期为 5 分钟。在等待绑定期间，过期后眼镜自动获取并播报新码，旧码立即失效。再次说“打开会议记录”会重播当前有效码。两个账号同时提交同一码，先在服务器完成绑定的账号获得眼镜，另一方看到验证码已使用或失效。绑定成功后验证码立即失效。

单次等待最长 15 分钟，超时后重新说“打开会议记录”即可继续。换账号时先在原账号解绑，再重新获取验证码绑定。

设备重启后凭证自动加载和校验，但不会自动恢复录音。网络失败明确中断，本地 WAV 可由设备维护者取回；不会自动补传。绑定密文与本机密钥的文件权限保护不等于硬件安全隔离。

录音上传到配套服务并按配置提交给外部 AI；设备还会保存本地 WAV。录音前告知参会者，核对转录和纪要中的关键事实。
